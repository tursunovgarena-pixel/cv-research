# Experiment Log

## Experiment 1

### Date

2026-08-06

### Goal

Investigate the visual effect of different image degradation methods on CIFAR-10 images.

### Dataset

CIFAR-10

### Applied degradations

- Brightness
- Contrast
- Gaussian Blur
- Gaussian Noise
- JPEG Compression

### Observations

- Brightness changes image illumination.
- Contrast changes object visibility.
- Gaussian Blur removes fine details.
- Gaussian Noise introduces random pixel disturbances.
- JPEG Compression creates compression artifacts.

### Conclusion

The degradation pipeline works correctly and produces visually distinct image corruptions.
