# Computer Vision Research Project

## Research Goal

Investigate how different image degradations affect the performance of computer vision models.

## Implemented

- CIFAR-10 dataset loading
- Dataset visualization
- Brightness degradation
- Contrast degradation
- Gaussian Blur
- Gaussian Noise
- JPEG Compression
- Automatic degradation pipeline
